## 🏆 Featured Projects & Case Studies

### 🏢 組織DX：Google Workspace導入と業務自動化
**Role: Project Lead / Developer**
* **Challenge**: シャドーITの横行と、散在する情報による低生産性。
* **Solution**: Google WorkspaceによるID統合管理と、AppSheet/GASを用いた定型業務の自動化パイプライン構築。
* **Impact**: セキュリティリスクを排除しつつ、検索・伝達コストを削減。**月間の残業時間をほぼゼロ**にする労働環境改善を実現。

### 🧩 AI民主化：社内用Chrome拡張機能の開発
**Role: Developer**
* **Challenge**: 生成AIの「プロンプトエンジニアリング」の難易度が高く、現場での利用が進まない。
* **Solution**: 業務ブラウザ上で動作する拡張機能を内製開発。「ボタンを押すだけ」で要約・翻訳・リスク判定が可能なUIを提供。
* **Impact**: API利用によるデータ保護（学習回避）を担保しつつ、**全社的なAI活用ハードルを極小化**。高額なSaaSを導入せずに内製で課題を解決。

### 🏥 福祉・医療領域 DXプラットフォーム刷新
**Role: Product Owner / PM**
* **Scale**: 大規模リニューアルプロジェクト / 開発チーム13名統括
* **Impact**: ネイティブアプリではなく**PWA**を採用し、TCO（総保有コスト）を大幅圧縮。浮いたリソースをマーケティングへ戦略配分し、事業ROIを最大化。

### 🗺️ 地域情報プラットフォーム「ねりキッズ探検団」
**Role: Full-stack Developer (Solo)**
* **Concept**: [nerikids.tokyo](https://www.nerikids.tokyo/)
* **Tech**: Vue.js, Supabase, Mapbox
* **Impact**: 構想からDB設計、Mapboxを用いた高度な地図実装、デプロイまでを**完全一人で完遂**。スケーラビリティを確保した本格的なWebサービス構築事例。
