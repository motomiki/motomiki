# 只野公朋｜Google Workspace × AI 👋

**AI に任せる仕事と、プログラムに任せる仕事を分けて作るエンジニアです。**

情シス・DX推進の現場で、Google Workspace の導入から社内での AI 活用までを担ってきました。
いまはその経験をもとに、中小企業の業務改善を支援しています。

| 💼 AIとなりの相談役                                                                                                                                                                   | 🧱 マイクラ教育版 × AI探究                                                            |
| :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | :------------------------------------------------------------------------------------- |
| Google Workspace を使う中小企業・NPO の相談役として、業務を仕分け、Gemini と GAS を組み合わせた仕組みを設計・実装しています。作った仕組みは、現場の方が自分で直せる形で引き継ぎます。 | 教育版マインクラフトと AI を使った探究学習を実践し、その様子を note で発信しています。 |

## 現場の困りごとを、道具にしてきました

| 困りごと                                       | つくったもの                                                                                                                                                                                                                           |
| :--------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 問い合わせの返信に、1件20分ほどかかっていた    | メールが届くと Gemini が返信の下書きを作り、Chat で知らせる「AI秘書」。最初は GAS で書き、のちに Workspace Studio へ移して、コードを書けない人でも直せるようにした                                                                     |
| 月20〜30通の請求書を、毎月手で作っていた       | Chat のボタンから、請求書 PDF つきの Gmail 下書きまでを作る仕組み。金額は生成 AI ではなく GAS で計算し、チェック前は発行しない・二重に発行しない・途中で止まっても続きから再開できる、という止め方を先に組み込んだ。送信だけは人が押す |
| 生成 AI はプロンプトが難しく、社内で使われない | ボタンひとつで要約や翻訳ができる、社内向け AI の Chrome 拡張                                                                                                                                                                           |
| 社外秘のデータを、外部の AI に渡せない         | Ollama / Open WebUI で、社外にデータを出さずに使える AI 環境                                                                                                                                                                           |
| 保護者との出席連絡が煩雑                       | 保護者と運営者をつなぐ出席連絡アプリ（PWA）                                                                                                                                                                                            |
| スクール運営の会員・予定・出欠の管理           | 運営をまとめて管理できるアプリ                                                                                                                                                                                                         |
| 子どもの練習の意欲を育てたい                   | タイピングの成果がカードになる、AI を使った学習記録アプリ                                                                                                                                                                              |

**つくり方**

- 企画から本番運用、操作マニュアルの整備まで、一人で担います
- 無料枠や、すでにある環境に収まるように設計し、運用コストを抑えます
- つまずいたことも記録に残し、ほかの人が引き継げる形にしています
