# 只野公朋｜Google Workspace × AI 👋

**いまある Google Workspace で、業務はもっと楽になります。**

情シス・DX推進の現場で、Google Workspace の導入から社内での AI 活用までを担ってきました。
いまはその経験をもとに、中小企業の業務改善を支援しています。

| 💼 AIとなりの相談役                                                                                                                                                                              | 🧱 マイクラ教育版 × AI探究                                                            |
| :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------- |
| Google Workspace を導入済みの中小企業に向けた、月額制の業務改善の相談サービスです。AI に任せる仕事と、GAS などの簡単な自動化で足りる仕事を分けて提案し、最後は自社で回せる形にしてお渡しします。 | 教育版マインクラフトと AI を使った探究学習を実践し、その様子を note で発信しています。 |

## これまでの仕事から

- Google Workspace への移行と、GAS / AppSheet による定型業務の自動化で、残業を大きく減らしました
- ボタンひとつで要約や翻訳ができる、社内向け AI の Chrome 拡張を内製しました
- Ollama / Open WebUI で、社外にデータを出さずに使える AI 環境を構築しました
